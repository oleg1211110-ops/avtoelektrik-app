OBD-II fault codes

What OBD-II is, how to read codes, what the letters and numbers mean, and why you shouldn’t just clear the codes.

When the Check Engine light comes on, the control unit has already stored a fault code in its memory. Any driver can read it — all you need is a scan tool.

What is OBD-II?

OBD-II is the on-board diagnostics standard. In the US it has been mandatory for passenger cars since 1996; in Europe its equivalent, EOBD, applies to gasoline cars from 2001 and to diesels from 2004. Today the vast majority of passenger cars have an OBD-II connector.

The connector is a 16-pin, trapezoid-shaped socket. It’s usually under the dashboard on the driver’s side, near the steering column, sometimes behind a cover or in the center console. Trucks have their own system with SPN and FMI codes — the app can decode those too.

How to read the codes

  1. Plug the scan tool into the connector.
  2. Switch on the ignition or start the engine — whichever the scan tool asks for.
  3. Select the engine control unit and read the fault codes.
  4. Write down or photograph all the codes, their descriptions and the “freeze frame” if there is one — the conditions when the fault appeared: rpm, temperature, speed.
  5. Look up what they mean on the “Error codes” tab.
It’s best to get a Launch scan tool — it’s proven equipment. Cheap ELM327 adapters can sometimes “crash” the car’s electronics.

Don’t leave a wireless adapter plugged into the connector all the time: many of them draw current and can drain the battery if the car sits for a long time.

No scan tool on hand? Many cars show their codes without one — by flashing the Check Engine light or as a number on the instrument cluster. How to do it on your make is on the “Error codes” tab → “Self-diagnosis”.

What the letters and numbers mean

A code consists of a letter and four digits, for example P0301. The letter shows the system:

  • P — powertrain: engine and transmission.
  • C — chassis: ABS, suspension, steering.
  • B — body: airbags, climate control, comfort systems.
  • U — communication between units, the CAN bus.

The first digit: 0 — a generic code, the same for all makes; 1 — a manufacturer-specific code whose meaning depends on the make. You’ll also come across 2 and 3. The following digits narrow down the component and the fault. For example, for P codes a third digit of 3 means ignition and misfires: P0300 — random misfire, P0301 — misfire in cylinder 1. Other common codes: P0171 — system too lean, P0420 — catalyst efficiency below threshold.

Important: a code tells you what the control unit saw, not which part to replace. P0171 can be caused by an air leak, weak fuel delivery or a faulty sensor — replacing the oxygen sensor at random makes no sense.

Why you shouldn’t just clear the codes

  • The cause is still there, and the light will come back on.
  • The freeze frame is erased along with the code — the mechanic loses a clue.
  • The system readiness monitors are reset, and the control unit needs time to run them again.
  • You can miss something serious: misfires, for example, destroy the catalytic converter.

The right order: read the codes, write them down, find and fix the cause, then clear them and check on a test drive that the fault doesn’t come back.

Key points
  • OBD-II is the diagnostics standard; the 16-pin connector is usually under the dashboard on the driver’s side.
  • Code letter: P — engine and transmission, C — chassis, B — body, U — communication between units.
  • A 0 after the letter means a generic code; a 1 means a manufacturer code.
  • A code describes what the control unit saw, not which part to replace.
  • Find and fix the cause first, then clear the code and check on a test drive.

How does a P0xxx code differ from a P1xxx code?
  • P0 is a generic code for all makes, P1 is a manufacturer code
  • P0 is a minor fault, P1 is a serious one
  • It isn’t — they’re the same thing
