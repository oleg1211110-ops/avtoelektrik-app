Common Rail injector coding (IMA)

Every Common Rail diesel injector has its own flow tolerance, and a calibration code is written on it (IMA/IQA). After replacing an injector this code is programmed into the unit with a scan tool — otherwise imbalance, smoke and a rough miss.

Common Rail injectors are made to the tiniest tolerances, and each flows a little differently. So the unit delivers evenly across the cylinders, an individual calibration code is marked on the injector (by make — IMA, IQA, ISA, C2I). That code describes its characteristic.

What to do after replacement

Fitted a new or reconditioned injector — its code must be entered into the unit with a scan tool for the right cylinder. Skip it and the unit assumes the old characteristic and delivers wrong: cylinder imbalance, smoke, a rough miss, harsh running.

Other injector adaptations

Besides coding, the unit does a zero-fuel-quantity learn and a per-cylinder correction (balance) — fine tuning for wear. Done with a scan tool per the make’s procedure. And separately check the injector return (leak-off) — a large return means wear (ties in with the diesel course).

Replaced a Common Rail injector — program its code right away. It’s not “optional”: without coding it will miss and smoke even with a new, good injector.
Key points
  • Every CR injector has its own flow; the calibration code (IMA/IQA etc.) describes its characteristic.
  • After replacement the code is programmed into the unit for the cylinder — otherwise imbalance, smoke, a miss.
  • Also: a zero-fuel-quantity learn and per-cylinder balance; check the injector return.

Check yourself

Why does a Common Rail injector have a calibration code (IMA)?
  • For looks
  • Every injector has its own flow; the code describes its characteristic so the unit delivers evenly across the cylinders
  • It’s a batch number
  • It’s the date of manufacture

Answer: Every injector has its own flow; the code describes its characteristic so the unit delivers evenly across the cylinders — CR injectors have a tiny spread in flow. The individual code (IMA/IQA etc.) describes the characteristic of that specific injector so the unit compensates the difference and delivery is even across all cylinders.

You fitted a new CR injector and didn’t program the code. What happens?
  • Nothing
  • Cylinder imbalance, smoke, a rough miss — the unit delivers by the old characteristic
  • The engine will never start
  • The injection pump will break

Answer: Cylinder imbalance, smoke, a rough miss — the unit delivers by the old characteristic — Without the programmed code the unit assumes the previous characteristic and delivers wrong for the new injector: per-cylinder imbalance, smoke, a rough miss, harsh running — even if the injector is good.
