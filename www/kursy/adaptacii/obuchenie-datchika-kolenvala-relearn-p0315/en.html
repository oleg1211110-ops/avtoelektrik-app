Crankshaft sensor relearn (P0315)

After replacing the crankshaft sensor or the ECU, or a repair around the pulley, the unit has to relearn the crankshaft rotation variation — otherwise it can't detect misfires accurately and sets code P0315.

To detect misfires accurately, the unit compares how fast each tooth of the crankshaft reluctor passes. But the ring and sensor have a tiny spread, so the unit “learns” this variation once — that's the crank relearn (CASE).

When a relearn is needed

After replacing the crank sensor or the reluctor ring, replacing or reflashing the ECU, and sometimes after an engine repair. If the relearn isn't done, the unit can't reliably tell misfires apart and sets P0315 (“crankshaft rotation variation not learned”).

How it's done

With a scan tool: start the relearn procedure and perform the required mode — usually accelerate to a set rpm and let off the throttle to zero (deceleration fuel cutoff) while the unit reads data. The conditions (warm-up, rpm) are per the make's procedure; on some cars the relearn happens in normal driving.

P0315 doesn't mean “the sensor is broken,” it means “the relearn wasn't done.” Fitted a crank sensor — don't forget the relearn with a scan tool, or you may get false misfires and the code returns.
Key points
  • The unit learns the crankshaft rotation variation so it can detect misfires accurately.
  • A relearn is needed after replacing the crank sensor, the reluctor ring or the ECU; without it, code P0315 sets.
  • It's done with a scan tool per the procedure (accelerate and let off the throttle); on some cars in normal driving.

Check yourself

What does code P0315 mean?
  • The crankshaft sensor is broken
  • The crankshaft rotation variation isn't learned — a relearn must be done
  • Low oil pressure
  • Misfires in cylinder 15

Answer: The crankshaft rotation variation isn't learned — a relearn must be done — P0315 is “Crankshaft Position System Variation Not Learned”: the unit hasn't learned the crankshaft rotation variation. It's not a broken sensor but an unperformed relearn — done with a scan tool.

When is a crank relearn needed?
  • At every oil change
  • After replacing the crank sensor, the reluctor ring or the ECU
  • Only on diesels
  • Never

Answer: After replacing the crank sensor, the reluctor ring or the ECU — A relearn is needed when the crank sensor, the reluctor ring or the control unit were replaced (and sometimes after an engine repair). Without it the unit can't tell misfires apart accurately and sets P0315.
